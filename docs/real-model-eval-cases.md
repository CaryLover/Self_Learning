# 真实模型小规模评测用例

用途：在完成物理预览验收后，用**未参与调试**的题目检查“输入 → 分流 → 工具/讲解 → 练习”的整体表现。  
这不是正确率认证；即使全部通过，也只能说明这些小样例可用。真实调用会产生模型费用，运行前需要使用者提供 key 或明确授权。

## 使用方式

1. 普通学科题用线上默认构建或本地开发服务器；物理题必须用本地 `VITE_ENABLE_PHYSICS=true` 预览构建。
2. 每个用例至少重复 2 次；记录模型厂商、模型名、日期、学段、耗时和失败情况。
3. 先看是否正常完成，再人工判断讲解、图、练习和安全边界；不要只看页面是否出现。
4. 图片题需要使用者自己提供清晰照片；不要使用调试阶段用过的图片。

## 用例

| 编号 | 学段/学科 | 输入 | 预期处理 | 人工核对重点 |
|---|---|---|---|---|
| E01 | 小学科学 | 为什么天空看起来是蓝色的？ | 普通 ELI5，不走物理工具 | 口语化、图与解释一致；不引入超纲术语 |
| E02 | 小学数学 | 3/4 和 5/8 哪个大？为什么？ | 普通 ELI5 | 分数比较方法不超纲；图与结论一致 |
| E03 | 初中数学 | 一次函数 y = -2x + 3 的图像经过哪几个象限？ | 普通 ELI5 | 图像、斜率和象限结论一致 |
| E04 | 初中物理 | 质量 1.5 kg 的物块在 20° 固定光滑斜面上，只受重力和支持力，g 取 9.8 m/s²。求斜面对物块的支持力和物块加速度。 | 预览分流进入斜面适配 | 图有重力/支持力；N≈13.81 N，a≈3.35 m/s²；讲解不引入摩擦 |
| E05 | 初中物理 | 用滑轮组提升重物为什么能省力？ | 工具不支持，走未核验文字退路 | 明确标注未核验；不展示确定的物理图或编造数值 |
| E06 | 高中物理 | 质量 3 kg 的物体由竖直绷紧的绳悬挂静止，只受重力和绳的拉力，g 取 10 m/s²。求绳的拉力。 | 预览分流进入悬挂适配 | 图中可见绳索；T=30 N；方向竖直向上 |
| E07 | 高中物理 | 热传导为什么总是从高温物体传向低温物体？ | 工具不支持，走未核验文字退路 | 不展示固定物理图；文字退路持续标注未核验 |
| E08 | 高中生物 | 光合作用的光反应和暗反应有什么联系？ | 普通 ELI5 | 图形式适合生物过程；物质与能量关系不混淆 |
| E09 | 语文 | 记叙文里的插叙有什么作用？ | 普通 ELI5 | 用时间轴/关系图而非坐标图；例子符合文体 |
| E10 | 英语 | 现在完成时和一般过去时有什么区别？ | 普通 ELI5 | 用对比表/句子对照；不强行画数学图 |
| E11 | 图片题 | 使用者提供一张清晰的题目照片 | 普通 ELI5 图片流程 | 先列出图中关键文字/数字/条件；图与题一致 |
| E12 | 条件不足 | 一个三角形的面积是多少？ | 要求补充条件，不编造答案 | 出现补充条件状态；不生成确定数值或练习 |
| E13 | 跨学科 | 为什么运动员跑步时心跳会加快？ | 普通 ELI5 | 图形式服从主题；不误入物理工具 |

## 物理独立计算

- E04：\(N = mg\cos\theta = 1.5 \times 9.8 \times \cos 20° \approx 13.81\ \text{N}\)；\(a = g\sin\theta = 9.8 \times \sin 20° \approx 3.35\ \text{m/s}^2\)。
- E06：静止悬挂 \(T = mg = 3 \times 10 = 30\ \text{N}\)。

这些计算只用于核对工具结果；图形是否画对、讲解是否一致仍需人工判断。

## 汇总口径

- 分别报告“全部用例中自动完成的比例”和“实际展示结果中人工判定正确的比例”。
- 单列失败类别：格式错误、网络失败、工具失败、条件不足、超范围、图形/讲解不一致。
- 报告用例数量、模型版本、重复次数和日期；不要用这 13 个样例宣称 90% 或覆盖全部学科。
- 图片题和条件不足题没有通过时，优先检查是否把“不确定”误当成确定答案。
