# 已知问题与后续改进

## KI-001：未切换年级时仍可能回答超纲内容

- 记录日期：2026-11-13
- 来源：使用者人工验收 A+B+C 时发现
- 现象：问了一道初中物理“平均速度”题，但没有切换年级，应用仍然作答；使用者认为这属于超纲。
- 当前处理：**本版不修改，后续再评估**。保留现有年级提示和讲解约束；没有把这个问题伪装成已修复。
- 后续方向：需要先明确“年级边界”的产品规则——是硬性拒答、提示切换年级，还是只在讲解深度上降级；再决定是否在请求前加入年级匹配检查。不能仅靠提示词保证不超纲。

## KI-002：物理编译器首次冷加载可能失败一次

- 记录日期：2026-11-13
- 现象：物理预览上线后首次冷加载编译器曾出现“物理编译器加载失败”，重试后成功；随后浏览器内下载约 4 秒。
- 当前处理：物理资源请求已增加 3 次短重试；失败时仍保留“重新生成讲解”入口。需要继续观察首次访问和部署传播期间的表现。

## KI-003：模型输出偶发中文错字

- 记录日期：2026-11-13
- 现象：英语时态样例第二次出现“到目前为至”（应为“到目前为止”）。
- 当前处理：属于生成文本质量问题，暂不为此增加硬编码替换；后续可在通用质量抽查中观察。
