# 通用看图讲解开发检查

目的：检查网站是否围绕 ELI5 的“大图、少字、面向第一次接触的人”组织讲解，同时兼顾学段和原题条件。下面是开发用输入，不能当作未参与调试的独立题库，也不能依据少数样例宣称正确率。这里不包含密钥、真实用户图片或历史对话。

## 如何记录

在同一题目的对照中固定模型及版本、学段、输入方式和生成设置；不同题目不要求同一版式。记录日期、模型、学段、是否有图片、是否生成讲解和练习、耗时、失败原因及人工观察。不要记录 API key 或个人信息。图片题使用获得许可且无个人信息的图片。

| 编号 | 学段 | 输入或情景 | 重点观察 |
|---|---|---|---|
| G01 | 小学 | 为什么植物需要阳光？ | 用简单的因果关系说明，图文与年级相符。 |
| G02 | 小学 | 1/2 和 1/4 哪个大？ | 图中整体一致，分割数量和比较结论一致。 |
| G03 | 小学 | 为什么有白天和黑夜？ | 地球与光照关系清楚，不把白天黑夜误说成地球绕太阳公转造成。 |
| G04 | 初中 | 用图解释水循环。 | 蒸发、凝结和降水的方向与名称一致。 |
| G05 | 初中 | 一个数的平方是 9，这个数可能是多少？ | 不遗漏负数解，讲清条件。 |
| G06 | 初三 | 帮我理解二次函数图像的开口和顶点。 | 按初三已学范围解释，图与文字一致。 |
| G07 | 初中 | 电池、灯泡和开关怎样连接才能让灯亮？ | 清楚表示闭合回路；说明示意图条件，不保证可直接作为实际电路施工指导。 |
| G08 | 初中 | 用一张图理解记叙文中的时间顺序。 | 主题适合文科，图解有助理解，文字不过量。 |
| G09 | 高中 | 通过一个生活例子解释能量转化与守恒。 | 区分系统内转化和向外传递，必要时说明前提。 |
| G10 | 高中 | 解释函数图像中的平均变化率。 | 图上两点、割线和公式含义一致。 |
| G11 | 高中 | 用图解说明细胞膜的选择透过性。 | 说明影响通过的物质及条件，不把膜描述为任意物质都能通过。 |
| G12 | 高中 | 用图解比较并列与递进关系。 | 不因学段或文科主题强行套用数学解题方法。 |
| G13 | 任意 | 上传清晰、无个人信息的图表，附完整问题。 | 模型识别输入图、讲解条件与练习题面；不能仅凭程序请求含图片就认定识别正确。 |
| G14 | 任意 | 上传数字无法辨认的题目图片。 | 模型如判断缺条件，应指出缺什么；不能捏造数字或继续给出确定答案。 |
| G15 | 任意 | “一个图形的面积是多少？”不提供图和尺寸。 | 判断条件不足，并说明需要什么信息；不应擅自构造原题的答案。 |
| G16 | 任意 | 用不支持图片的模型上传图片。 | 页面应提示切换支持图片的模型，不能假装模型看到了图。 |

题目描述、SVG 和练习分别检查，不因为页面正常打开就判定知识正确。图片不清或问题不完整时，能否正确报告缺失依赖模型；提示词、元数据和格式检查都不能证明它一定发现了缺失条件。

## 检查维度

| 项目 | 判断依据 |
|---|---|
| 首次理解 | 图文是否解释了必要概念，例子是否真正帮助理解。 |
| 学段适配 | 术语、方法和难度是否适合学生已学内容；课程进度可能随教材和地区不同。 |
| 图文一致 | 图中的关系、方向、标签和正文是否一致，有无关键遮挡或裁切。 |
| 输入忠实 | 是否保留用户给定条件；图片中的文字、数值和关系是否识别正确。 |
| 练习可用 | 题目是否自包含，答案与解析是否成立，是否与讲解的主题和条件一致。 |
| 不确定性 | 条件缺失、模糊或题目超出已知范围时，是否明确说明，而不是编造。 |
| 恢复与兼容 | 失败或取消后已生成讲解是否保留，能否单独重试练习；模型、代理与历史会话是否仍可用。 |

## 已有程序检查

`cd web` 后运行 `npm run test:eli5`、`npm run test:eli5-view`、`npm run test:proxy-settings` 和 `npm run test:grade-prompt`，分别检查生成编排、界面状态、代理设置和学段提示词。启动 `node dev/mock-vendor.mjs` 后可打开本地开发服务器的 `eli5-probe.html`，检查浏览器中的图片传递、代理、失败重试与条件不足流程。模拟接口返回固定内容，不评估真实模型的知识、视觉理解或讲解质量。
