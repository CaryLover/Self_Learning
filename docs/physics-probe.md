# 物理编译验证记录

2026-11-12：本地 Node.js 和桌面 Chrome 浏览器验证，使用 typst.ts 0.7.0、typed-physics 0.3.0、CeTZ 0.5.2、oxifmt 1.0.0。Typst 的归档由 `dev/fetch_typst_packages.py` 从官方包站下载；项目本地保存固定版本及哈希。npm 包版本已写入依赖及锁文件。

执行 `cd web` 后运行 `npm run test:typst-probe`。Node 测试暂时使用 Windows 的 Arial 和 Cambria 字体，仅用于本机验证，不随网站发布。浏览器原型使用本地 New Computer Modern 字体，随附来源和许可证；测试还依赖本机 Typst 归档及三项 npm 包。

已验证：

- 固定物理描述经 Typst 编译，输出场景与受力图的 SVG。
- 编译后通过 metadata 获取同一场景的 `status`、`model`、支持力和加速度。4 kg、30°、重力加速度 9.81 m/s² 的光滑斜面样例，与 `mg cos θ`、`g sin θ` 的独立计算一致。
- 一个双物体接触案例的 `model-of` 返回 `none`。
- Chrome 本机测试可以输出 SVG 和结果；此样例的重力箭头向下，支持力箭头垂直斜面向外。开发服务器会对 `.tar.gz` 返回 gzip 传输编码，浏览器自动解压后会使二次解包失败；测试静态资源改用 `.bin` 文件名，并检查 gzip 文件头。
- 浏览器已运行光滑斜面和竖直悬挂静止两个模拟模型的端到端样例：提取题面依据、生成图文、计算核对、拦截条件不足。极小角度例子中物理库将加速度取成零，独立数值校验会拒绝该结果。
- 物理包的受力枚举会输出力的种类和方向，程序将它们与独立规则比较。此检查不代替对最终 SVG 箭头几何和画面布局的验收。
- 编译器原始 WASM 大于 Cloudflare Pages 的 25 MiB 单文件限制。独立构建在输出前压缩为约 10.84 MB 的 `.bin` 资源，运行时在后台线程解压并校验原始文件 SHA-256。Node 测试使用真实解压数据完成两类求解；受控 Chrome 浏览器也成功请求压缩资源，并完成解压、校验及两个模拟模型样例。在 390 × 844 的模拟视口下，两个样例和取消任务检查同样通过；这不是手机实机测试。浏览器不支持 `DecompressionStream` 时明确报错。
- `cc.query()` 在当前版本会因世界未编译失败；应在同一个 `runWithWorld` 内先编译再查询。SVG 和查询目前分别编译同一份源，正式接入时仍应评估共享编译及状态同步。

**尚未验证：** 更多浏览器、手机内存与加载时间、可分发中文和数学字体、其他题型的图内遮挡与箭头视觉审核、题目解析和练习。数值一致不能证明题目识别正确或其他图形正确。本机测试未接入学生页面，不构成产品能力或 90% 正确率结论。原「人和板」题仍超出当前已验证范围。

当前已有开发环境专用入口：高中学段的看图讲解中，题目前加 `【物理测试】`。目前仅处理已明示质量、角度、固定光滑斜面和「只受重力和支持力」的单物体题，或已明示质量、静止、固定竖直绷紧的绳和「只受重力与绳拉力」的悬挂题；不支持图片。它会标注待审核，不能作为正式教学内容。原文包含某个片段并不能证明模型理解了其语义；自动计算通过也不等于题面识别正确。该入口只在 Vite 开发模式启用，生产构建不会开放。

正式接入前仍须完成压缩资源在更多浏览器及部署环境的验证、依赖及字体许可审查、资源加载与隔离策略、图形和文字的一致性检查、超范围处理及独立题库评测。当前正式构建没有启用物理入口，也没有输出压缩编译器；不能只取消开发模式限制就发布。不要将任意模型输出直接作为 Typst 源码执行。
