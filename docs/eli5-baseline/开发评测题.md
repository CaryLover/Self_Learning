# ELI5 开发评测题

这些题用于开发和排查问题，不用于计算正式正确率。对照时记录模型、版本、设置、时间、题目、图片输入、重复次数、页面与失败原因；不要记录 API key。物理题应由具有相应专业能力的人审核。

| 编号 | 学段 | 题目 | 检查重点 |
|---|---|---|---|
| 01 | 小学 | 为什么先算乘法再算加法？ | 从零解释、图文对应 |
| 02 | 小学 | 什么是分数 3/4？ | 图形等分 |
| 03 | 小学 | 周长和面积有什么不同？ | 图形对比 |
| 04 | 小学 | 水为什么会蒸发？ | 条件与表达准确 |
| 05 | 小学 | 植物怎样利用阳光？ | 简化但不误导 |
| 06 | 小学 | 小数 0.5 和 1/2 有什么关系？ | 数值一致 |
| 07 | 初中 | 什么是一次函数的斜率？ | 概念由浅入深 |
| 08 | 初中 | 为什么负负得正？ | 类比与规则 |
| 09 | 初中 | 串联和并联电路有什么区别？ | 图文一致 |
| 10 | 初中 | 光从空气斜射入水中会怎样？ | 法线与方向 |
| 11 | 初中 | 质量 2 kg 的物体静止在水平桌面上，分析其受力 | 研究对象、方向 |
| 12 | 初中 | 光滑斜面上的物块受到哪些力？ | 法线与重力 |
| 13 | 初中 | 汽车运动时摩擦力一定与运动方向相反吗？ | 相对运动趋势 |
| 14 | 高中 | 从零解释牛顿第二定律 | 术语与条件 |
| 15 | 高中 | 匀速圆周运动是否需要受力？ | 向心方向、避免重复列力 |
| 16 | 高中 | 用绳悬挂的物体静止，分析受力 | 绳方向 |
| 17 | 高中 | 静摩擦力一定等于摩擦因数乘支持力吗？ | 静摩擦取值 |
| 18 | 高中 | 人站在板上并拉动绕过滑轮的绳，分析人和板 | 未提供图形及条件，要求补充 |
| 19 | 初中 | 有一个物块，分析它受到的所有力 | 条件不足，不能猜测 |
| 20 | 初中 | 附带模糊题目照片，请解释图片中的题 | 图片不清时要求补充 |
| 21 | 高中 | 为什么导数可以描述瞬时变化？ | 分步解释与学段适配 |
| 22 | 高中 | 对比动量和动能 | 对比图、适用条件 |

受力图的评估同时检查研究对象、施力来源、是否漏力或多力、方向、作用位置以及遮挡；原始人板题须使用明确的题面和图形另做回归测试。截图与自动格式检查不证明物理正确。
