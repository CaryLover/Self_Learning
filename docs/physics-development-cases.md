# 物理融合开发用例

这些题目用于调试当前开发原型，不是独立验收题库，也不能用于宣称达到某个正确率。当前显式物理测试入口面向高中纯文字题，支持单物体光滑固定斜面、竖直悬挂静止、限定的人板静力和有界纯电阻直流网络；预览分流在初中只自动尝试悬挂和电路，图片题和小学题不自动进入。生成的结果仍需人工复核。

## 测试方法

启动 `web` 开发服务器，在网站选择高中和「看图讲解」，将题目全文复制到输入框，题目前加 `【物理测试】`。使用自己的模型配置，不要在记录中保存 API key 或其他凭据。每次使用同一模型及设置记录模型名称、版本、日期、耗时和结果；有条件时重复测试并记录每次结果。

预期「候选」是指题目属于当前支持范围，应尝试生成并显示待审核结果，仍须检查原文理解、图、文字和练习；预期「复核」是指必须停止生成确定的物理解答，显示需要复核或明确报错。请求失败、超时和数值校验失败应单独记录，不能记作题目正确识别。仅凭页面出现就判定通过是不够的。

## 开发题目

斜面答案按 $N=mg\cos\theta$、$a=g\sin\theta$ 独立计算；悬挂答案按 $T=mg$ 独立计算。近似值以 N 和 m/s² 为单位。表中的文本需要连同首尾条件完整输入。

| 编号 | 题目 | 预期 | 人工核对点 |
|---|---|---|---|
| I01 | 质量4 kg的物块在固定光滑斜面上，斜面倾角30°，物块只受重力和支持力。取重力加速度9.81 m/s²，求受力、支持力和加速度。 | 候选 | $N≈33.98$，$a≈4.905$；重力向下，支持力垂直斜面向外。 |
| I02 | 单个质量2 kg的物块位于固定光滑斜面上，倾角为30°，它只受重力和支持力，取重力加速度10 m/s²。求支持力和加速度。 | 候选 | $N≈17.32$，$a=5$。 |
| I03 | 固定光滑斜面的倾角为60°，一个质量3 kg的物块只受重力和支持力，取重力加速度10 m/s²。求支持力和加速度。 | 候选 | $N=15$，$a≈8.66$。 |
| I04 | 一个质量5 kg的物体在固定光滑斜面上，斜面倾角45°，它只受重力和支持力。取重力加速度10 m/s²，求受力和加速度。 | 候选 | $N≈35.36$，$a≈7.07$。 |
| I05 | 一块质量1 kg的物块在固定光滑斜面上，斜面倾角30°，物块只受重力和支持力。求支持力和加速度。 | 候选 | 重力加速度未给出，必须标明使用的假设；数值按所标假设核算。 |
| H01 | 质量2 kg的物块由一端固定、竖直绷紧的绳悬挂并静止，物块只受重力和绳的拉力。取重力加速度10 m/s²，求受力和拉力。 | 候选 | $T=20$；重力向下、拉力向上。 |
| H02 | 一个质量3 kg的物体由上端固定、竖直绷紧的绳悬挂并静止，只受重力和绳的拉力。重力加速度为9.8 m/s²，求绳的拉力。 | 候选 | $T=29.4$。 |
| H03 | 一个质量1 kg的物体由固定、竖直绷紧的绳悬挂并静止，只受重力和绳的拉力。求拉力。 | 候选 | 重力加速度未给出，必须标明使用的假设；数值按所标假设核算。 |
| R01 | 质量4 kg的物块在固定光滑斜面上，物块只受重力和支持力。取重力加速度9.81 m/s²，求支持力和加速度。 | 复核 | 缺少角度。 |
| R02 | 一个物块在倾角30°的固定光滑斜面上，只受重力和支持力，取重力加速度10 m/s²，求支持力。 | 复核 | 缺少质量。 |
| R03 | 质量4 kg的物块在倾角30°的固定斜面上，只受重力和支持力，取重力加速度10 m/s²，求支持力。 | 复核 | 原型要求题面明确说明光滑。 |
| R04 | 质量4 kg的物块在倾角30°的光滑斜面上，只受重力和支持力，取重力加速度10 m/s²，求加速度。 | 复核 | 原型要求明确说明斜面固定。 |
| R05 | 质量4 kg的物块在倾角30°的固定光滑斜面上，取重力加速度10 m/s²，求加速度。 | 复核 | 没有明确排除额外外力。 |
| R06 | 质量4 kg的物块在倾角30°的固定粗糙斜面上，只受重力、支持力和摩擦力，取重力加速度10 m/s²，求加速度。 | 复核 | 有摩擦，不在当前模型范围。 |
| R07 | 质量4 kg的物块在倾角30°的固定光滑斜面上，除了重力和支持力还受到外力F，取重力加速度10 m/s²，求加速度。 | 复核 | 存在额外外力。 |
| R08 | 质量2 kg的物块由一端固定、竖直绷紧的绳悬挂，只受重力和绳的拉力。取重力加速度10 m/s²，求拉力。 | 复核 | 没有明确静止，不能由悬挂推断静止。 |
| R09 | 质量2 kg的物块由一端固定的绳悬挂并静止，只受重力和绳的拉力。取重力加速度10 m/s²，求拉力。 | 复核 | 题面未明确绳竖直绷紧。 |
| R10 | 质量2 kg的物块由一端固定、竖直绷紧的绳悬挂，但物块并不静止。它只受重力和绳的拉力，取重力加速度10 m/s²，求拉力。 | 复核 | 明确否定静止；还应留意题面条件是否自洽。 |
| R11 | 一个质量为2 kg的人站在质量为3 kg的木板上，板与地面接触，绳子连接人和板。求各物体所受的力。 | 复核 | 人、板、接触与绳构成多物体问题，不可套单物体模型。 |
| R12 | 一块质量4 kg的物块在固定光滑斜面上，斜面倾角0°，只受重力和支持力，取重力加速度10 m/s²，求受力。 | 复核 | 当前模型角度范围不含 0°，即使题目本身可能有解也不能套用。 |

|---|---|---|---|---|---|---|---|---|---|---|
